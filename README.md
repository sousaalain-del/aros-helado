# Aros de Helado

Juego de aros de agua para el teléfono, con tema de helado.

- Inclina el teléfono para mover los aros.
- Toca la pantalla para lanzar el chorro de agua.
- Mete los 12 aros en las dos varitas.

Jugar: https://sousaalain-del.github.io/aros-helado/

En iPhone: abrir en Safari, tocar **¡Jugar!**, aceptar el permiso de movimiento y luego Compartir → *Añadir a pantalla de inicio*.
